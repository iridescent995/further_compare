# Further Compare 2.51.0

Folder column widths can now be adjusted while keeping both panes aligned. Drag either boundary to give names, sizes or modification dates more room. Preferences persist on the device and fit the current window.

Focus a boundary and use Left/Right arrows to adjust it; Shift uses larger steps. Home or double-click resets a column. Escape cancels an active drag. Reset both widths from **View → Reset column widths** in the folder context menu or **View → Folder Layout → Reset Column Widths** in the native menu.

Validation covered mouse/keyboard adjustment, cancellation, invalid saved values, persistence, responsive bounds and unchanged sort/selection. Both packaged Mac architectures passed real-folder tests including expanded nodes, both reset menus and compact row geometry. The rendered folder layout was inspected.

Mac arm64, Mac x64 and Windows x64 archives passed integrity and bundled-source verification. Download links, sizes, SHA-256 and the Windows ZIP browser download passed. Windows runtime verification and the broader full-product work remain pending.
