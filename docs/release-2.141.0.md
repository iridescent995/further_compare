# Release 2.141.0 — Registry context actions

Registry Compare now uses the shared context menu for opening inputs, exporting results, copying selected entries, initializing either side as the result, all three filters and page navigation. Missing inputs, missing selection, pending loads and page boundaries disable unavailable commands. Blank-space and row menus support keyboard navigation, with native text/select context menus retained.

Captured callbacks validate the exact selection, state and revision before acting. Old callbacks cannot mutate a newer selection or restored session. Same-side file opens use request tickets so the latest request wins. Cancelled pickers retain existing inputs and edited results. Pending loads block copy, initialization and export. Redraws preserve focused rows or editable result selection when focus was inside the registry view, without taking focus from other views.
