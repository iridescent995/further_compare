# Release 2.145.0 — Three-way merge history and context actions

Three-way merge now reviews replacement of manually edited results when a conflict choice changes. Undo/redo restores choices and result text, including an intentionally empty result. Opaque runtime history survives tab switches and binds to all three sources and the exact result. Cancelled file pickers preserve history; committed input replacements clear it. Save is disabled while conflicts remain unresolved or inputs are loading.

A grouped right-click menu provides file opening/saving, conflict navigation, resolution in either concatenation order, history and supplied archive-entry actions. Conflict and unresolved-conflict navigation updates selection, focus and scroll without rebuilding the editor. Native next/previous commands use the same navigation. Native textarea context menus remain available. Stale callbacks and unavailable actions are guarded. Conflict cards are borderless and use pastel buttons with dark ink in both themes.

Source validation passes: merge-history browser/native, merge-context browser/native, shared Table Compare context regression, history unit tests, and existing advanced swap integration. The swap test now waits for a uniquely identified loaded session and idle operations before dispatching native commands, avoiding its previous race between identically named sessions. Exact UTF-8 and empty exports, both merge orders, per-tab history, review cancellation/acceptance, stale callbacks, pending inputs, selection/focus and unchanged original files are covered. Both-theme screenshots and computed button colors/card borders were checked.

Both final Mac packages pass merge-history and merge-context native tests. All three ZIP integrity checks pass; package versions and final website assets match. Download links, sizes, SHA-256 and Windows ZIP browser download pass. Shipped branding scan has no matches. Actual Windows runtime and remaining full-product capabilities are outstanding.
