# Release 2.147.0 — Background three-way merge computation

Three-way merge calculations run in a dedicated worker. Source changes cancel superseded work; request identity, generation, session state and source bindings prevent stale results from applying. Source-content caching avoids repeated calculations for presentation and result edits. An eight-second deadline terminates stalled work. Errors keep Save disabled while exposing Retry and Undo recovery. Sources remain editable while comparison is pending; snapshots remain synchronous and preserve manual output.

Real-worker browser tests verify exact output, caching, cancellation, stale responses, error/timeout recovery and IME composition during an initial pending request. A costly 1,400-line differing-input fixture retained 28 renderer heartbeat updates with a longest observed gap of 25.6 ms. Browser live/history/context harnesses now use an HTTP origin and the production worker bundle. Native source tests verify loading the real file-based worker, latest-source behavior, pending guards, history/tab restoration and exact exports. Existing live/history/context and advanced swap regressions pass.

A separate stress limitation remains: Playwright native textarea fill (CDP Input.insertText) with 24,000 lines stalled Chromium's renderer insertion path and reached about 6.4 GB peak memory. The same input assigned through the DOM and dispatched as an input event passed worker processing and history checks. This does not prove physical clipboard paste behaves identically. The optional FC_MERGE_NATIVE_PASTE=1 stress reproduction is retained in test/merge-worker-desktop.cjs; the default worker test retains the same input size via DOM assignment. This release does not claim to fix that insertion stall.

Both final Mac architectures pass the real-worker and live-editing tests. Native history checks explicitly verify either one grouped edit or two edits separated by debounce, including exact intermediate values, reverse redo order and preservation across tab switches. All three ZIPs pass integrity checks; packaged versions, worker and UI assets match the final build. Download links, sizes, SHA-256 and Windows browser download pass. Shipped branding scan has no matches. Actual Windows runtime, the native bulk-insertion limitation above and remaining full-product capabilities are outstanding.
