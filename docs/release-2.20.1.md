# Further Compare 2.20.1

The folder context menu groups related actions into submenus instead of placing every command in one long scrolling list. Common opening and file operations remain directly available. Comparison types, tree expansion, selection, layout, sorting, comparison rules, navigation and reports retain their existing actions and selection restrictions.

Submenus support mouse and keyboard navigation and adjust their placement near window edges. Focus and hover colors follow the current light or dark theme.

All 153 unit tests pass. The new desktop suite checks the action inventory, right-side and directory actions, compact layout, hover switching, disabled items, arrow/Home/End navigation, Escape/Tab dismissal, focus restoration, preserved multi-selection, and light/dark placement at the bottom-right edge. Existing desktop, queued-command, timestamp, report, rules, explicit-comparison and external-editor regressions also pass.

Both final Mac packages pass the grouped-menu suite. The versions, menu code, renderer and styles in all three packages match source. ZIP integrity and download link, size and SHA-256 checks pass.

The broader full-product scope and native Windows runtime validation remain in progress.
