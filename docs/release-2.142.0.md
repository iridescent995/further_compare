# Release 2.142.0 — Grouped archive context menus

Archive Compare now uses the shared context-menu tree. A compact root exposes opening archives, editing, save/extract and selection/view groups, alongside the selected row's open or expansion action. All previous leaf actions retain their review dialogs and behavior. Opening either archive and Collapse all are also available by right-click. Empty trees and blank space support keyboard menu access; native dialog controls retain their context menus.

Captured callbacks validate the exact archive references, session context, focused path and selection. Rendering, loading and selection changes invalidate existing menus. Open actions remain available during source replacement but are disabled during editing/saving or without a desktop file picker. Keyboard navigation, disabled-item skipping, focus restoration and viewport-constrained submenus use the shared implementation.

Eleven native tests were adapted to navigate the new groups without weakening their existing operation assertions. Light and dark screenshots were inspected.
