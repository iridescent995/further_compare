# Release 2.135.0 — Optional blank-line comparison

Optional blank-line ignoring is available for text and normalized folder comparisons, shared by child comparisons, sessions, defaults, reports, CLI and batch jobs. Empty and spaces/tabs-only physical lines are ignored independently of whitespace scopes; nonbreaking spaces remain content. Files containing nonblank text retain final-newline significance.

Original lines remain visible as minor rows with their actual line numbers and absent-side null indexes. Manual blank/nonblank alignment overrides suppression. Merge sections exclude ignored internal blank rows. Removing a final newline can necessarily remove empty trailing separators; spaces/tabs payload is retained. Randomized bidirectional merge checks cover this exception.

Browser checks pass minor rows, final newlines, NBSP distinctions and synchronized scrolling through ignored gaps. Native folder/session/report/default/copy tests pass, including actual text merges that preserve internal blanks and resolve the final newline. Both final Mac packages passed the native blank-line workflow and actual merge checks. All three ZIPs passed integrity checks; versions, shared/native modules and final renderer assets match source.
