# Further Compare 2.28.0

File → External Editor now supports ordered file-type profiles alongside the default application. Add a named profile, enter filename patterns separated by semicolons, and choose the system default or a custom application with arguments. Move profiles up or down to change precedence, disable them temporarily, or remove them. Changes are saved only with Save preferences; Cancel preserves existing settings.

The first enabled matching profile wins. Patterns match the filename, not its directory, and ignore letter case on every platform. `*` matches any characters and `?` one character; other punctuation is literal. For example, `*.java; *.xml` matches either extension, and `Dockerfile` matches that exact filename. Unmatched files use the default application. Up to 32 profiles with 32 patterns each are supported.

Routing applies to existing text, folder and advanced-input external-editor commands. Each profile uses the same literal argument handling and native file checks as the default editor. Enabled custom applications are checked when saving; disabled profiles may retain unavailable applications. A missing selected application reports an error rather than silently opening a different editor. Existing preferences remain compatible when no profiles are configured.
