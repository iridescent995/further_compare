# Release 2.143.0 — Binary context actions

Binary Compare now exposes file opening/saving, page and difference navigation, alignment mode, byte/range editing, copying the current difference, undo/redo and byte-field focus through a grouped right-click menu. Archive-entry actions appear when supplied by the parent session and reuse the existing review callbacks.

Right-click targets a physical right-file byte while retaining an existing range containing that byte. Selecting does not modify data. Keyboard access and focus restoration work across rebuilt panes. Native input and dialog context menus remain available. Menu actions validate current state, selection, input requests, fields and availability. Input replacement invalidates menus immediately, disables writing until settled and preserves the latest same-side request. Replaced or disabled archive-entry callbacks cannot execute.

Advanced toolbar actions now explicitly use pastel backgrounds with dark ink in both themes, correcting low-contrast text found during visual review.

Source validation: 27 binary alignment/edit/history unit tests, existing binary runtime tests, new browser and native context workflows, and workbook theme/import regression pass. Tests cover exact edited/exported bytes, containing ranges, review cancellation, undo/redo, navigation, native controls, stale callbacks, injected archive actions and toolbar ink in both themes. An archive integration check exposed a cancel/reopen race: the queued close event from an earlier review could clear the new review. The close handler now clears review state only while the dialog is actually closed. The extended native integration passes after the fix. A deterministic native regression verifies a trusted queued close event arriving while the new dialog is open, followed by exact edited-byte export with unchanged originals; it passes in source and the final Intel package. Binary context workflows pass on both Mac architectures, and both final rebuilt packages pass the extended archive-entry integration. All three final ZIP integrity checks, packaged versions/assets, download links/sizes/SHA-256 and Windows ZIP browser download pass. Shipped branding scan has no matches. Actual Windows runtime and remaining full-product scope are outstanding.
