# Further Compare 2.35.0

Three-way folder merge compares a base folder with left and right revisions. Independent changes combine automatically; conflicting files and subtrees require an explicit base, left or right choice. The review includes searchable paths, collapsible hierarchy and paginated results.

Choose a separate output folder to preview exact changes, including deletions and file/directory replacements. Native confirmation identifies the output and operation count. Input folders remain read-only. Saved sessions retain folder choices and require fresh analysis when reopened.

Before application, affected output files are backed up and incoming content is staged and verified. Recovery records show reverse operations for completed or interrupted changes. Confirming a restore backs up the current output and creates another recovery record, allowing that restore to be undone. Changed output or backup data invalidates a review.
