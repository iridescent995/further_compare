Upstream MIT license is retained verbatim in CALAMINE-LICENSE-MIT.md, copyright Johann Tuffe2016. Their application metadata says Microsoft Excel16.0300; this is not authenticated producer authorship. Call these independently sourced XLSB files, not files generated by this project. They contain VBA payloads which admission never executes or forwards; originals remain test data only.

Adjacent *-libreoffice.xlsx are independent LibreOffice readbacks of the original XLSB, not replacements for genuine binary fixtures. Reproduce using `soffice --headless --convert-to xlsx --outdir <temporary-directory> <original.xlsb>`, then rename resulting XLSX. Inspect with openpyxl `load_workbook(...,data_only=False)` and `data_only=True`. LibreOffice can normalize formula spelling (notably CONCAT) and recalculate caches; the expected semantic expression/source bytes remain separate evidence.

Independent readback:

- issue_182: formula_vals A1 `=1+2` cache3; A2 `=_xlfn.CONCAT("A", "b")` cacheAb; A3 `=ISERROR(1)` cachefalse. Three formula records, four BrtName records, no shared or array formula groups. `_xlfn.CONCAT` is admitted only through the specifically qualified future-function declaration and invocation profile; removed sheet references in other names remain unresolved.
- issues: datatypes A3 and issue6 A3 `=CONCATENATE("a","b")`, corresponding A4 `=A1>A2`; Sheet1 A2 `=B1+OneRange`. Five formula records, three BrtName records (MyBrokenRange, MyDataTypes, OneRange), no shared/array groups. OneRange resolves to Sheet1!$A$1. Broken name remains a distinct reference-error definition.

Coverage limits: these files do not establish shared/array, all ptg families, external workbooks, tables or calculation fidelity. Group-record mutations in this test are explicitly synthetic structural/adversarial controls, not independent producer coverage. Separate POI group qualification is tracked independently.

Admission references: Microsoft MS-XLSB BrtName/NameParsedFormula, BrtExternSheet/Xti, BrtShrFmla/BrtArrFmla; brtRevisionPtr requires other consumers to ignore it. BrtUid is a16-byte identifier; BrtCalcFeature contains FRTBlank+XLWideString inside its recognised future-record collection. PageSetup, linked printer settings, calculation chains and VBA are excluded from the new parser-only cached-value package. Unknown records remain refused.

The actual-reader qualification compares every formula against `independent-readback.json`, then runs the whole-sheet comparator. LibreOffice writes the `=A1>A2` false caches as numeric zero; that particular oracle is explicitly interpreted as boolean false, matching the original XLSB boolean-cache record. A separately labelled token mutation changes `1+2` to `2+1` while retaining cache3, proving expression comparison does not rely on cache differences.

CellParsedFormula, ArrayParsedFormula and SharedParsedFormula token lengths are restricted to 1–16384 bytes. NameParsedFormula admits an empty definition as unavailable context (as seen in independently sourced unknown-function stubs), never as a decoded expression; nonempty definitions have the same 16384-byte bound. The narrowly qualified offline external-link profile admits only missing-path relationship descriptors with bounded sheet names and empty error-cache collections. Targets are never resolved, fetched, or forwarded to the cached-value parser; external formula identities remain unavailable. Active external caches, other external relationship types, and worksheet metadata remain outside this profile.
