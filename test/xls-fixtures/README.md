# Controlled XLS fixture

`libreoffice-control.xls` is a project-owned synthetic two-sheet workbook generated by `test/legacy-workbook-spike.cjs` using ExcelJS to create XLSX and **LibreOfficeDev 26.8.0.0.alpha0** (build `2c87e51eeaa2b413ff4ae097b2705eea1995d8e5`) to export **MS Excel 97 / BIFF8 XLS**. SheetJS was not used to create it. It contains 16 populated cells: numeric cached formulas, a boolean, Unicode, multiline text and a literal formula-looking string.

SHA-256: `1b4cddde5fc6291f740fac7971e375f3de604c4aaaed4af295e436bff25eb266`.

The generation and independent LibreOffice → XLSX → ExcelJS value readback are documented in `docs/legacy-workbook-qualification.md`. This fixture proves that producer/profile only, not arbitrary Excel/BIFF variants or source-preserving edits.
